Title: Real-time Comments Platform (.NET 11 + Angular)

Description:
A full-stack single-page application where visitors post comments, reply to them (unlimited nesting), attach images or text files, and see new comments from other users instantly.

Highlights:
• ASP.NET Core API with Entity Framework Core and PostgreSQL (3-layer architecture, interfaces everywhere)
• Angular + Angular Material + Tailwind front end, client- and server-side validation
• Rich text with a strict tag whitelist (XSS-safe), live preview, one-time image CAPTCHA
• Image upload with automatic resizing in a background queue, lightbox viewer
• Domain events, in-memory caching with invalidation, SignalR WebSockets
• 69 xUnit tests, Docker Compose deployment, running on an AWS server

Skills: ASP.NET Core, Angular, PostgreSQL, Docker, SignalR, Entity Framework
